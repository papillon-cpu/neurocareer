# NEUROCAREER — архитектура

## Стек MVP (версии проверены 30.10.2026)

- Next.js 16.4 (App Router), React 19, TypeScript, Tailwind CSS 4
- PostgreSQL + ORM (Prisma или Drizzle — выбор на этапе 3 после проверки совместимости стабильных версий; у Prisma 8 в npm пока `rc`)
- Auth.js, Zod, S3-совместимое хранилище, Playwright + Vitest

## Принципы

1. **Модульность.** `src/modules/<domain>` (assessments, matching, billing, ai, resume, consent) — бизнес-логика без UI и без прямых вызовов БД из компонентов.
2. **Название — конфиг.** Бренд хранится в `src/config/brand.ts`, смена названия — одно место.
3. **Деньги и лимиты — конфиг.** Тариф (1 000 ₽/мес, 50 контактов, 200 ₽ за доп. контакт) лежит в `src/config/pricing.ts` как значения по умолчанию; на этапе 8 переедут в `AdminSettings` в БД.
4. **Баллы считает код.** Проверка тестов — детерминированная; AI не меняет ключи и шкалы.
5. **AI Gateway.** Единая точка для Claude/GPT: таймауты, лимиты, валидация ответов по Zod, учёт стоимости, учёт согласий перед отправкой данных провайдеру.
6. **Приватность по умолчанию.** Контакты и результаты тестов отдаются работодателю только по отдельному согласию. Права проверяются на сервере при каждом действии.
7. **Честные интеграции.** Не настроено → явная ошибка/пометка, никаких фиктивных «успехов».

## Дизайн-система

Тёмная графитовая основа, акцент — кислотно-лаймовый («нейрон»), вторичный — холодный фиолетовый. Заголовки — Unbounded, текст — Onest (оба с кириллицей), моно — JetBrains Mono. Токены заданы в `src/app/globals.css` через `@theme`.

Компоненты: `src/components/ui` (Button, Card, Badge, Section), состояния загрузки/ошибки/пусто добавляются вместе с первыми реальными экранами данных (этап 3).
