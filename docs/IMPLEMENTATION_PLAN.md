## Структура маршрутов (целевая)

- `/` — лендинг
- `/(auth)/login`, `/(auth)/register` — вход и регистрация
- `/me/*` — кабинет сотрудника (profile, assistant, tests, reports, resume, jobs, career, privacy)
- `/company/*` — кабинет работодателя (vacancies, candidates, favorites, history, billing, settings)
- `/admin/*` — администрирование
- `/api/*` — серверные маршруты (webhooks оплаты, загрузка файлов)

## Риски

1. **Персональные данные (152-ФЗ).** Нужны юридически проверенные тексты согласий и политики; хранение данных в РФ — решить до продакшена.
2. **Методология тестов.** До валидации — только «предварительная оценка навыков и потенциала». Без выдуманных норм и процентилей.
3. **Платежи.** Реальный провайдер для РФ выбирается отдельно; до этого — явный sandbox.
4. **Стоимость AI.** Баллы тестов считаются кодом, модели — только там, где дают ценность.
5. **Дискриминация в подборе.** Чувствительные признаки не участвуют в оценке; решения остаются за человеком.

## Бизнес-правила (уточнено заказчиком)

**Сотрудник:** разовая оплата **500 ₽** (значение настраивается) **до** начала. После оплаты открывается всё: три теста, отчёты, редактор резюме, сборка резюме с AI, импорт старого резюме, AI-консультант. Публикация профиля в базе кандидатов — только после отдельных согласий и проверки резюме (этап 9). Реализация (этап 8): таблица доступа сотрудника + единая проверка `requireEmployeeAccess` в страницах и серверных действиях + `BillingProvider` (sandbox до подключения реального провайдера). До этапа 8 функции открыты для разработки.

**Работодатель:** подписка **1 000 ₽/мес** (настраивается). Входит: публикация вакансий, просмотр до **50 уникальных контактов** за период, каждый следующий **200 ₽**, AI-подбор релевантных резюме.

**Ограничения:** AI получает данные только при отдельном согласии на внешние AI-провайдеры; тесты — собственная методика без заимствования заданий и шкал сторонних методик (в т. ч. PIF/ЭКОПСИ).
