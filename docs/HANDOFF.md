# Памятка для продолжения работы

Репозиторий: приватный, ветка `feat/foundation-landing`. Проверки: `npm run typecheck && npm run lint && npm test && npm run build` (тесты идут по одному файлу: в каждом своя встроенная БД).

## Готово
1. План, архитектура, дизайн-система, лендинг
3. Регистрация и вход, роли, кабинеты
4. Резюме: редактор, версии, импорт PDF/DOCX с проверкой, печать в PDF
5. Три авторских теста, отчёты
6. AI-шлюз (Claude и GPT), консультант, AI в резюме, AI-пояснение к отчёту (нужны ключи, на живых моделях не проверялись)
8. Оплата: 500 ₽ доступ сотрудника, подписка работодателя, контакты (тестовый провайдер)
7. Вакансии и подбор: вакансии с модерацией, разбор требований (AI или правила), объяснимый подбор по опубликованным профилям, история и жалобы, открытие контактов с показом цены
9. Приватность: публикация, контакты, отзыв, удаление, журнал

## Осталось
- **Этап 10.** Playwright-сценарии, инструкция по деплою (хостинг + управляемый PostgreSQL), чек-лист запуска, подключение реального платёжного провайдера по интерфейсу `BillingProvider`.
- Юридическая проверка текстов согласий (`src/modules/consent/texts.ts`, версия `2026-10-draft-1`), сроков хранения и политики удаления.

## Заметки по этапу 7
- Демо-данные для ручной проверки: `npm run db:seed -- --demo`, затем `npx tsx scripts/seed-demo-matching.ts` (останавливайте dev-сервер: БД `.data/` открывается одним процессом). Админ для локальной проверки: `ADMIN_EMAIL`/`ADMIN_PASSWORD` при `db:seed`.
- Не проверено на живых моделях: `vacancy_analysis` и `match_explain` (нет ключей); нужны согласие кандидата `ai_matching` и тексты согласия на проверку юристом (добавлен текст `ai_matching`, версия `2026-10-draft-1`).
- Известные ограничения: см. конец раздела «Вакансии и подбор» в docs/ARCHITECTURE.md.
