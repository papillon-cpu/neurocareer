# Как выложить NEUROCAREER в интернет

Что нужно: сервер, где работает Node.js (или Docker), управляемая база PostgreSQL и домен с HTTPS. Данные пользователей из РФ по 152-ФЗ нужно хранить на серверах в РФ, поэтому хостинг и базу выбирайте российские (например, Selectel, Yandex Cloud, VK Cloud, Timeweb Cloud; сравните цены и условия сами). Окончательное решение по хранению данных принимает юрист.

Эта инструкция не проверялась на живом сервере: у меня нет вашего хостинга. Проверена только локальная сборка (`npm run build`) и все тесты.

## 1. Что подготовить

| Что | Зачем |
|---|---|
| Сервер или контейнерный хостинг (от 1 ГБ памяти) | Запуск приложения |
| Управляемый PostgreSQL 15+ | База. Включите ежедневные резервные копии |
| Домен и HTTPS-сертификат | Куки сессии отмечены `secure`, без HTTPS вход не заработает |
| Ключ ИИ: GigaChat (Сбер; работает из России, оплата в рублях), Anthropic или OpenAI | AI-функции. Из России Anthropic и OpenAI официально недоступны. Без них сайт работает, AI показывает «не подключён» |
| Платёжный провайдер | Реальная оплата. Без него в production оплата недоступна (не имитируется) |

## 2. Переменные окружения

Задаются в панели хостинга или в файле `.env` на сервере. В git их не кладут.

| Переменная | Обязательна | Значение |
|---|---|---|
| `NODE_ENV` | да | `production` (ставит `npm run start` сам, в Docker уже задана) |
| `DATABASE_URL` | да | `postgres://пользователь:пароль@хост:5432/база` (с `?sslmode=require`, если база требует) |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | для первого запуска | Создают администратора командой `npm run db:seed`. Пароль не короче 12 символов |
| `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL` | для AI | Ключ из console.anthropic.com |
| `GIGACHAT_AUTH_KEY`, `GIGACHAT_MODEL` | для AI из России | Ключ авторизации и название модели из кабинета developers.sber.ru. Доп.: `GIGACHAT_SCOPE` (по умолчанию `GIGACHAT_API_PERS`, для ИП и организаций `GIGACHAT_API_B2B` или `GIGACHAT_API_CORP`), `GIGACHAT_BASE_URL`, `GIGACHAT_OAUTH_URL`. Если сервер не доверяет сертификату Сбера, добавьте корневой сертификат Минцифры через `NODE_EXTRA_CA_CERTS=путь/к/файлу.pem` |
| `YANDEX_API_KEY`, `YANDEX_FOLDER_ID`, `YANDEX_MODEL` | для AI из России | API-ключ сервисного аккаунта Yandex Cloud, идентификатор каталога и модель (например `yandexgpt/latest`). Доп.: `YANDEX_BASE_URL` |
| `AI_PRIMARY_PROVIDER` | нет | `gigachat`, `yandex`, `anthropic` или `openai`. Без значения берётся первый настроенный провайдер |
| `OPENAI_API_KEY`, `OPENAI_MODEL` | по желанию | Запасной AI-провайдер, `AI_FALLBACK_PROVIDER=openai` |
| `BILLING_PROVIDER` | для оплаты | Имя подключённого провайдера. Пусто в production = оплата выключена. **Не ставьте `sandbox` на боевом сайте**: это имитация без денег |
| `BILLING_WEBHOOK_SECRET` | для оплаты | Секрет подписи уведомлений провайдера |
| `DEMO_MODE` | нет | **Не задавайте на боевом сайте.** Включает вход в демо-аккаунты без пароля |

Остальные AI-лимиты и переопределения описаны в `.env.example`.

## 3. Первый запуск

```bash
npm ci
npm run build
npm run db:migrate        # создаёт таблицы в PostgreSQL
ADMIN_EMAIL=... ADMIN_PASSWORD=... npm run db:seed   # создаёт администратора
npm run start             # сайт на порту 3000
```

Через Docker: `docker build -t neurocareer .`, затем
`docker run --rm --env-file .env neurocareer npm run db:migrate`, затем
`docker run -d -p 3000:3000 --env-file .env neurocareer`.
(Dockerfile не собирался на этой машине, проверьте на сервере.)

Перед сайтом поставьте обратный прокси с HTTPS (Nginx, Caddy или встроенный балансировщик хостинга), который передаёт запросы на порт 3000.

## 4. Обновление версии

1. Получить новый код, `npm ci`, `npm run build`.
2. `npm run db:migrate` (миграции только добавляют, но резервную копию сделайте заранее).
3. Перезапустить `npm run start`.

Откат: вернуть прежний код и восстановить базу из копии, если миграция уже применилась.

## 5. Проверка после запуска

- `https://ваш-домен/api/health` отвечает `{"ok":true}`: приложение работает и база отвечает. Подключите эту ссылку к мониторингу.
- Войдите администратором, откройте «Тарифы» и «Журнал».
- Пройдите чек-лист из `docs/LAUNCH_CHECKLIST.md`.

## 6. Ограничения текущей версии

- **Почта.** Для сброса пароля задайте `APP_URL`, `RESEND_API_KEY`, `MAIL_FROM`. Без них в production письма не уходят. Ограничение частоты общее (в БД), несколько экземпляров допустимы.
- Загруженные файлы резюме не хранятся (только извлечённый текст), отдельное файловое хранилище не нужно.
- Письма (сброс пароля, уведомления) пока не отправляются: сброса пароля нет.
- Реальный платёжный провайдер не подключён: добавляется реализацией `BillingProvider` (`src/modules/billing/provider.ts`), webhook принимает `POST /api/billing/webhook/<провайдер>` и без верной подписи отвечает 401.
