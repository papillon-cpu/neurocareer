# NEUROCAREER

AI-платформа карьерного развития и подбора сотрудников (название временное — `src/config/brand.ts`).

## Запуск

```bash
npm install
npm run dev          # http://localhost:3000, БД создаётся сама в папке .data (PGlite)
npm run db:seed -- --demo   # необязательно: демо-пользователи (пароль выводится в консоль)
```

Для PostgreSQL задайте `DATABASE_URL` (см. `.env.example`) и выполните `npm run db:migrate`.
Администратор: `ADMIN_EMAIL=... ADMIN_PASSWORD=... npm run db:seed`.

## Проверки

```bash
npm run typecheck && npm run lint && npm test && npm run build
```

## Статус

Готово: лендинг, регистрация и вход, роли (сотрудник / работодатель / администратор), кабинеты с реальной заполненностью профиля, профиль и компания, учёт согласий, резюме (редактор, версии, два шаблона, импорт PDF/DOCX с проверкой, печать в PDF), три теста потенциала с автосохранением и отчётами (Soft Skills, аналитика, управленческий потенциал; предварительная оценка по собственной методике).
AI-шлюз (Claude и GPT), карьерный консультант, AI в резюме и AI-пояснение к отчёту реализованы, но **требуют ключей** и согласия пользователя (см. `.env.example`); с реальными моделями не проверялись.
Оплата: разовые 500 ₽ за доступ сотрудника и подписка работодателя 1 000 ₽ с учётом контактов реализованы с **тестовым** провайдером (реальные деньги не принимаются, провайдер подключается отдельно). Тарифы меняются в `/admin/pricing`.
Не реализовано: AI-проверка свободных ответов, вакансии и подбор, публикация профиля, вакансии и подбор, оплата. Тексты согласий — черновик, нужна юридическая проверка.
